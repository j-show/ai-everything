# 修复续跑

核对当前 requirement.md 与确认记录；回调时沿用原 ID、参数与有效确认，不覆盖用户编辑。既有 proposal.md 不作为修复前置，也不修改。

确认需求阶段完成记录与当前内容一致后，按用户交付终点恢复：

- 仅文档：交付 requirement.md。
- 尚未修复：进入主流程第 2 节。
- 已修复待审查或验收：检查编号、修复差异和调查证据，恢复 `fix.md` 对应环节；红绿或审查证据缺失先补齐。

文件存在不代表批准。返回验收不满足或需求有未确认变化时，回调 grilling-requirement。已有执行方式沿用，同一缺陷实际修复失败次数保留。
