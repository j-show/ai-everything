# 修复续跑

ID、需求模板和需求阶段续跑由已安装的 grilling-requirement 维护；本入口传入 pre-tag=DD，返回 task-id 记为 dd-id。新 ID 使用八位日期；历史任务按公共技能的续跑规则保留原目录。

确认需求阶段完成记录与当前内容一致后，按用户交付终点恢复：

- 仅文档：交付 requirement.md。
- 尚未修复：进入 Step 4。
- 已修复待审查或验收：检查编号、修复差异和调查证据，进入 Step 4 对应环节；红绿或审查证据缺失先补齐。

文件存在不代表批准。未决不为无、内容变化未确认或缺少书面澄清记录时，回调 grilling-requirement 的 Step 3。已有执行方式沿用，同一缺陷实际修复失败次数保留；不覆盖用户编辑。
