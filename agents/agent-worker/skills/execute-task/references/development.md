# 公共技能调用覆盖

此适配仅适用于已确认的单任务 brief。读取会话登记的 dev-requirement/dev-debug 及其 references，缺失或不可读回报主代理；不拿仓库同名文件冒充已登记调用，不修改公共技能默认契约。

| 任务 | 入口 | 仍需履行 |
| --- | --- | --- |
| feature | dev-requirement | 对应批准的任务技术做法、范围核对、TDD、审查反馈与最终验证 |
| bugfix | dev-debug | 原始复现、根因证据、实验恢复、TDD、审查反馈与复测；连续失败计数不因换代理归零 |

授权覆盖：主代理传入已确认行为及确认记录、做法/根方案约束、验收与允许文件范围，替代新建的子任务 requirement.md/proposal.md 及其存在性门禁。需要进一步技术推演时保存在任务状态与会话；涉及行为、边界或方案取舍的变化回主代理，不把免落盘理解为免批准。

不另建子任务流程文档、术语表或调查报告。README、AGENTS、接口说明等产品代码配套文档照常新增/更新，计入任务文件范围。公共技能的 TDD、根因调查、实验恢复、审查和验证算法保持引用，不复述或绑定其内部步骤号。

当前 worker 采用公共技能的当前会话实现与自审方式；仍加载 requesting-code-review 模板，明确标注缺少独立审查。最终整体 reviewer 闭环由主代理执行。

这些公共技能可能设置 disable-model-invocation；不将其填进预加载清单假定成功。当前用户已经授权本流程使用这些技能；合法调用不可用时，从会话登记路径读取其指令执行，权限限制或登记缺失则报告阻塞。
